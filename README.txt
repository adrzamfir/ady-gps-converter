ADY GPS CONVERTER

Conținut:
- index.html: aplicația
- manifest.webmanifest: setări instalare PWA
- sw.js: cache offline
- icon.svg: pictogramă

Publicare:
1. Încarcă toate cele 4 fișiere în același director al unei găzduiri web HTTPS.
2. Deschide adresa publicată pe telefon.

Instalare iPhone:
1. Deschide adresa în Safari.
2. Apasă Share / Partajare.
3. Alege Add to Home Screen / Adaugă la ecranul principal.
4. Apasă Add / Adaugă.

Instalare Android:
1. Deschide adresa în Chrome.
2. Apasă meniul ⋮.
3. Alege Install app / Instalează aplicația (sau Add to Home screen).

Conversia funcționează local; după prima încărcare, pagina poate fi folosită offline.
